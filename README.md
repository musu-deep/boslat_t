# البوصلة

واجهة إدارة المحتوى والوكلاء.

## التشغيل التجريبي

```sh
npm ci
npm run dev
```

عند غياب إعدادات الاتصال تعمل النسخة التجريبية تلقائيًا وتحفظ البيانات في المتصفح. لا تنفذ الوكلاء أو النشر الخارجي فعليًا. جميع بيانات البدء للتجربة فقط.

## الربط لاحقًا

اضبط VITE_SUPABASE_URL وVITE_SUPABASE_ANON_KEY في بيئة البناء ثم أعد البناء. بيانات المتصفح لا تنتقل تلقائيًا إلى قاعدة البيانات. يلزم تجهيز قاعدة البيانات وصلاحيات المستخدمين قبل الاستخدام الفعلي.
