# تشغيل الربط

واجهة GitHub Pages تتصل بخدمة منفصلة عبر HTTPS. ملف api/friday.js جاهز لاستضافة Node serverless مثل Vercel، ويستخدم محرك shared/friday-engine.js نفسه الذي يفحص النص داخل الواجهة.

1. انشر هذا المستودع على خدمة تدعم مسار api/friday.js. على Vercel اضبط مدة الوظيفة بما يسمح بـ60 ثانية على الأقل.
2. اضبط في الخادم OPENAI_API_KEY وOPENAI_MODEL (نموذج متاح لحسابك يدعم JSON عبر Chat Completions) وFRIDAY_ACCESS_TOKEN (رمز وصول عشوائي طويل خاص بالمحررين). ALLOWED_ORIGINS افتراضياً https://musu-deep.github.io، ويمكن تحديد مصادر إضافية مفصولة بفواصل.
3. من غروب الجمعة افتح إعداد الاتصال، وأدخل رابط الوظيفة https://YOUR-HOST/api/friday ورمز الوصول. الرابط يحفظ محلياً؛ الرمز في ذاكرة الجلسة فقط، ولا يوضع مفتاح OpenAI في المتصفح.
4. اختيارياً اضبط متغير المستودع VITE_FRIDAY_API_URL ليصبح الرابط الافتراضي عند بناء Pages.
5. أدخل المحور وولّد؛ المحرك يقارن مرشحين ويصلح كل مرشح حتى ثلاث محاولات. التقييم الدلالي تقديري. لا تحفظ ولا تعتمد مسودة غير مطابقة للقيود؛ يبقى اعتماد المعنى النهائي مسؤولية المحرر.

لا يشمل هذا التعديل إعداد مفاتيح حقيقية أو نشر خدمة خلفية. الموقع الحالي في الوضع التجريبي ويحفظ الإصدارات في المتصفح. حد الطلبات بالخادم مؤقت لكل نسخة تشغيل، ويحتاج بوابة حصص دائمة عند التوسع، مع هويات منفصلة للمحررين بدلاً من رمز الفريق المشترك.
